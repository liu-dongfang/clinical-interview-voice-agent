# Domain Demo

The original `bailing-main_01` repository explored structured interview workflows for assessment-style conversations.

In this showcase repository that domain is intentionally treated as a secondary example rather than the main identity of the project.

Why keep it:
- it shows that the speech pipeline can support more than open-ended chat
- it highlights dialogue control and state progression on top of the same backend interfaces
- it provides a concrete example of how scripted flow and free-form turns can coexist

Why de-emphasize it:
- the reusable engineering value is the interruptible voice-agent architecture
- the public repository should stay broad enough for interviews, collaboration, and reuse in other domains
- unpublished prompts, internal materials, and unfinished business logic should not define the public presentation

See [examples/structured_assessment_script.json](structured_assessment_script.json) for a small placeholder example of how a scripted workflow might be represented without bringing over private or unfinished materials.
